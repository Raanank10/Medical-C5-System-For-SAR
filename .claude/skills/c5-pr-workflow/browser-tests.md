# Per-feature browser and wire tests

Moved verbatim from `CLAUDE.md` (where it was loaded into every session) so it is read only when choosing which tests to run. `npm test` (`scripts/run_tests.js`) still runs every one of these, and CI runs `npm test` on every PR. Run the ones that match the feature you changed locally first; they are faster than the whole suite.
