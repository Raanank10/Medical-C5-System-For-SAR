C5 Sentinel-SAR — Medical Command & Control for Disaster Response

A mission-critical, offline-first system for managing casualties, medics, and logistics in real-time during Search & Rescue operations.

Designed for high-stress environments where:

information is fragmented
time is critical
decisions must be immediate

🔥 What makes this different
Event-Sourced Architecture → full auditability & replay
Offline-First Sync → works in low-signal disaster zones
Clinical Watchdogs → automatic alerts (Crush Syndrome, Golden Hour)
Logistics Intelligence → real-time equipment tracking & burn rate
Command Visibility → heatmaps, funnels, and sector accountability

🎯 Core Value
This system reduces the Fog of War by providing:
Clinical Awareness — tracks patient deterioration and time-critical risks
Operational Control — ensures no casualty is lost or duplicated
Logistical Clarity — monitors supply consumption and resupply flow


🧪 Built As
📱 Mobile: React Native (Expo)
🖥️ Web: React + Tailwind
🧠 Backend: Supabase (PostgreSQL)
💾 Data Model: Event-Sourced, Append-Only

📊 Example Use Cases
Mass casualty incidents (earthquakes, building collapse, missles strikes)
Military SAR operations
Emergency medical coordination across multiple agencies


🚀 Status
MVP in development — focused on:
ultra-fast triage workflows
real-time decision support
reliable offline operation

Why this project matters (Data / Product Perspective)

This project demonstrates:

Designing a real-time data system under uncertainty
Building an event-driven data model from scratch
